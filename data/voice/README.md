# data/voice/ - SYNTHETIC audio

Synthetic demo audio. Spoken by OpenAI tts-1 from a script we wrote, transcribed by OpenAI whisper-1. It is not a recording of a real person and no real audience audio exists in this repo.

Every file in here was generated by `scripts/transcribe_voice.py --speak`. The
scripts we asked the TTS to read, the voice used and the transcript that came
back are all in `data/voice-notes.json`. Each mp3 also carries an ID3 tag saying
the same thing, so the label survives the file being downloaded on its own.

No real audience audio exists in this repository and none was ever collected.
